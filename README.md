# baloipro-petroleum-engineering
🚀 Baloipro – Petroleum Engineering Automation

Baloipro is a free petroleum engineering application designed to help petroleum engineers perform well performance analysis, validate well test data, and improve production modelling workflows.

The application brings together practical engineering tools in one place, helping engineers perform calculations, analyze production data, compare well performance, and support technical decision-making.

The goal is simple: make practical petroleum engineering tools more accessible and improve engineering workflow efficiency through automation.

---

✨ Key Features

1. Well Model Matching

Match well models against actual well test data and evaluate model performance.

2. Well Test Validation

Validate well test results and identify discrepancies between measured and modelled production data.

3. IPR/VLP Analysis

Perform inflow and outflow performance analysis to evaluate well deliverability and performance.

4. Production Analysis

Evaluate well performance and investigate production behavior using available engineering data.

5. Well Performance Evaluation

Compare actual versus predicted well performance to support engineering assessment and optimization.

6. Engineering Calculations

Access practical calculation tools for petroleum engineering applications.

7. More Engineering Tools

Additional engineering utilities and analysis features to support everyday petroleum engineering work.

⚙️ IPM Software & License Requirements

Important: Baloipro is an automation application, NOT a replacement for commercial IPM software.

For workflows involving IPM automation, Baloipro uses C++-based automation to interact with the relevant installed IPM applications.

The following IPM applications may be required, depending on the functionality being used:

- PROSPER – Well performance modelling and analysis.
- GAP – Integrated production system and network modelling.
- MBAL – Material balance and reservoir modelling.

License requirements:

- Users must have their own valid IPM licenses for the relevant applications.
- The corresponding IPM software must be properly installed and available on the computer.
- Baloipro does not include, provide, replace, or redistribute PROSPER, GAP, MBAL, or their licenses.
- IPM automation functionality depends on the availability and licensing of the corresponding IPM applications.

Baloipro acts as an engineering automation layer to support and streamline workflows involving these applications.
